The MIM synchronization engine (FIMSynchronizationService) orchestrates identity flows between multiple authoritative sources and target systems. At the center lies the Metaverse (MV) — a unified identity repository. Management Agents (MA) manage the Connector Spaces (CS) that link each connected system to the MV.

ℹ️
The synchronization server is SVMIMGLOASP01. Rules extensions are implemented via Lithnet.Umare.RulesExtension.dll (UMARE framework — Unified MA Rules Extension).

The Metaverse is the central repository of MIM. It contains 23 object types and 196 attribute types. The person type is the richest with 143 attributes.

Object types prefixed LMG_ are custom extensions specific to the client: LMG_BL (Business Lines), LMG_Unit, LMG_Site, LMG_Company, LMG_serviceAccount, LMG_adminAccount, LMG_exchangeObject, LMG_contact.

The AD MA is the connector to the Active Directory domain FromEarthToLife.net. It is the primary target system: MIM provisions and maintains user accounts, groups, contacts and computers in AD. It is the only MA with password synchronization enabled.

🔑
Password Sync enabled. Initial passwords (initialPasword) and reset passwords (resetPassword) are exported to AD via the unicodePwd attribute.

The FIM MA is the connector between the synchronization engine and the MIM Service (FIM Service). It synchronizes all MIM portal objects — users, groups, synchronization rules, etc. — with the Metaverse. It manages 151 export flows and 14 object types for joining.

⚠️
The FIM MA is bidirectional: it imports data from the MIM portal into the MV (e.g. modifications made via the self-service portal) and exports MV data to the portal (provisioning Person, Group, SynchronizationRule attributes, etc.).

The MDM RH IRIS - MA is now the primary HR connector to the iHris system. It fully replaces the MDM RH - Update New MA (obsolete) and provides all employee identity data: personal information, contract data (accountStartDate, accountExpires), LMG organizational referential codes (BL, Unit, Site) and language information.

✅

The MDM RH IRIS - Export is an output-only connector: it exports MIM-calculated data to the iHris system. This is a feedback mechanism: MIM sends back to the HR source the AD account information created (AccountName, UPN, mail...) so that the HR system is informed of the allocated AD login.

🔄
This 7-attribute flow closes the loop: iHris creates the employee → MIM creates the AD account → MIM sends back the AccountName and UPN to iHris for traceability.
