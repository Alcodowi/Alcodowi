Le moteur de synchronisation MIM (FIMSynchronizationService) orchestre les flux d'identités entre plusieurs sources autoritaires et les systèmes cibles. Au centre se trouve la Métaverse (MV) — un référentiel unifié d'identités. Les Management Agents (MA) gèrent les Connector Spaces (CS) qui font le lien entre chaque système connecté et la MV.

ℹ️
Le serveur de synchronisation est SVMIMGLOASP01. Les extensions règles sont implémentées via Lithnet.Umare.RulesExtension.dll (framework UMARE — Unified MA Rules Extension).

La Métaverse est le référentiel central de MIM. Elle contient 23 types d'objets et 196 types d'attributs. Le type person est le plus riche avec 143 attributs.

ℹ️
Les types d'objets préfixés LMG_ sont des extensions personnalisées spécifiques au client : LMG_BL (Business Lines), LMG_Unit, LMG_Site, LMG_Company, LMG_serviceAccount, LMG_adminAccount, LMG_exchangeObject, LMG_contact.

🔑
Password Sync activé. Les mots de passe initiaux (initialPasword) et réinitialisés (resetPassword) sont exportés vers AD via l'attribut unicodePwd.

Le FIM MA est le connecteur entre le moteur de synchronisation et le Service MIM (FIM Service). Il synchronise tous les objets du portail MIM — utilisateurs, groupes, règles de synchronisation, etc. — avec la Métaverse. Il gère 151 flux d'export et 14 types d'objets en jointure.

⚠️
Le FIM MA est bidirectionnel : il importe les données du portail MIM vers la MV (ex : modifications faites via le portail self-service) et exporte les données MV vers le portail (provisionnement des attributs Person, Group, SynchronizationRule, etc.).

Le MDM RH IRIS - Export est un connecteur en sortie uniquement : il exporte des données calculées par MIM vers le système iHris. Il s'agit d'un mécanisme de feedback : MIM renvoie vers la source RH les informations de compte AD créées (AccountName, UPN, mail...) pour que le système RH soit informé de l'identifiant AD alloué.

🔄
Ce flux de 7 attributs ferme la boucle : iHris crée l'employé → MIM crée le compte AD → MIM renvoie le AccountName et l'UPN vers iHris pour traçabilité.
