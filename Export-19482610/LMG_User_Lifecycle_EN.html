This document describes the complete lifecycle of a user resource in MIM: from its creation to permanent deletion, through all intermediate stages (AD provisioning, activation, blocking, deactivation, quarantine).

🔄
Reversibility: If EmployeeEndDate is pushed into the future, the account leaves the "End Date was 1 day ago" set and the MPR Set Active if EndDate is changed in future triggers to reactivate the account automatically.

After deactivation, the user enters a 180-day retention period before permanent deletion.

flowchart TD Q1["Inactive account\nin Quarantine OU in AD"] Q1 --> WAIT["⏳ Wait 180 days after EmployeeEndDate"] WAIT --> SET10["Set: Users - EmployeeEndDate +180 days\n/Person[\nEmployeeEndDate > now()+180d\nand DN ends with OU=Quarantine,...\nand Visible=True]"] SET10 -->|"Set Transition"| MPR13["📋 ## Users - Delete User (+180 days)\n⛔ CURRENTLY DISABLED\n(SetTransition)"] MPR13 --> WF23["⚡ Delete User (+180 days)\n→ DeleteResources\n(permanent deletion from MIM + AD)"] style Q1 fill:#1a1a1a,stroke:#455a64 style WAIT fill:#1a1a1a,stroke:#455a64 style MPR13 fill:#2a2a2a,stroke:#757575 style SET10 fill:#1a1a1a,stroke:#455a64
⚠️
Important note: The deletion MPR (## Users - Delete User (+180 days)) is currently disabled (Disabled = True). Deletions therefore do not happen automatically in the current state. A manual action or reactivation of this MPR is required to purge expired accounts.
